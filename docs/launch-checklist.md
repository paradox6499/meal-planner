# Чек-лист перед широким запуском «Съедим»

Собрано по ходу обсуждений в чате — не техническая документация (см. `server/README.md` и `docs/telegram-bot-architecture.md` для неё), а разовые организационные/юридические дела, за которыми нужно проследить лично.

## Юридическое / бизнес

- [ ] **ОКВЭД.** Текущий основной код ИП — 47.91 («Торговля розничная по почте или по интернету»), из дополнительных — 47.99, 59.20, 82.99. Ни одного IT-кода нет, хотя бизнес по факту продаёт доступ к приложению по подписке. Добавить дополнительным кодом **62.01** («Разработка компьютерного программного обеспечения») — подаётся бесплатно через Госуслуги/ФНС (форма Р24001), закрывать/переоткрывать ИП не нужно. Несовпадение ОКВЭД с реальной деятельностью — частая причина проблем при модерации/блокировках у платёжных систем.
- [ ] **Товарный знак на бренд «Съедим».** Регистрация в Роспатенте — защищает именно название и логотип от использования другими (отдельно от авторского права на код). Стоит уточнить точную стоимость и сроки у патентного поверенного — процесс небыстрый (обычно от 8-12 месяцев на полную регистрацию), поэтому чем раньше подать, тем раньше защита.
- [ ] **(Опционально) Регистрация программы для ЭВМ в Роспатенте.** Даёт официальное свидетельство на сам код — весомый аргумент в споре о копировании. Дешевле и быстрее товарного знака (пошлина в районе нескольких тысяч рублей, ~2 месяца), но защищает только буквальный код, не идею продукта.

## Репозиторий / защита кода

- [ ] **Сделать GitHub-репозиторий приватным.** Сейчас публично виден не только фронтенд, но и весь бэкенд, база рецептов, алгоритм подбора цен — самая ценная часть работы. Секретов/токенов в коде не найдено (не аварийная ситуация), но это самая быстрая и дешёвая реальная защита от копирования.
  - Личный аккаунт + GitHub Pages из приватного репо → нужен **GitHub Pro** (~$4/мес, сайт остаётся публичным, приватен только код).
  - Либо оставить репозиторий приватным бесплатно и перенести статику на **Vercel/Netlify** (бесплатный тариф поддерживает деплой из приватного репо) — придётся один раз перенастроить деплой вместо GitHub Actions → Pages.
