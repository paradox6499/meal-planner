Политика конфиденциальности «Съедим»

Действует с 10.09.2026

Настоящая Политика описывает, какие данные собирает мини-приложение «Съедим» (Telegram-бот @s_edim_bot, далее — «Сервис»), зачем и как ими распоряжается, в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

1. Оператор персональных данных

Индивидуальный предприниматель ИП Киселев Евгений Дмитриевич, ИНН 644302512981, ОГРНИП 322645700078520 (далее — «Оператор»). Связаться по вопросам обработки данных: @s_edim_bot (кнопка «Написать в поддержку» в разделе «Аккаунт») · genykis@yandex.ru.

2. Какие данные собираются

  • Из Telegram — идентификатор пользователя (telegram_user_id) и имя, которые Telegram передаёт Сервису автоматически при открытии мини-приложения (стандартный механизм Telegram Mini Apps, initData) — без этого Сервис не может отличить одного пользователя от другого.
  • Настройки плана, которые пользователь указывает сам: состав семьи, бюджет, диета, аллергии, приёмы пищи и время их приёма — нужны для составления плана и напоминаний.
  • События использования — какие шаги мастера пройдены, какие кнопки нажаты (например, «план собран», «открыт экран подписки»), без содержимого личных сообщений. Используется для того, чтобы понимать, что в Сервисе работает хорошо, а что нужно доработать.
  • Статус подписки и факт оплаты — что именно оплачено и когда. Сам номер карты и другие платёжные реквизиты Сервису не передаются и не хранятся — их получает и обрабатывает платёжный провайдер (ЮKassa) напрямую.

Отдельно: часть настроек (тема оформления, черновик профиля) хранится только в браузере/приложении пользователя (localStorage) и на сервер Оператора не передаётся вообще.

3. Цели обработки

  • формирование плана питания и списка покупок под указанные параметры;
  • отправка напоминаний о приёмах пищи в согласованное пользователем время;
  • предоставление платной подписки и подтверждение факта оплаты;
  • улучшение Сервиса на основе агрегированной статистики использования;
  • обратная связь по вопросам и ошибкам, если пользователь сам обращается в поддержку.

4. Кому передаются данные

  • ВкусВилл — при формировании корзины Сервис обращается к открытому каталогу товаров и ценам ВкусВилл; сама корзина собирается по ссылке, которую открывает пользователь, персональные данные пользователя ВкусВиллу не передаются.
  • ЮKassa — при оформлении платной подписки: обрабатывает оплату напрямую, минуя сервера Оператора.
  • Telegram — как платформа, через которую работает Сервис (отправка сообщений/напоминаний идёт через официальный Bot API Telegram).

Данные не продаются и не передаются каким-либо ещё третьим лицам.

5. Срок хранения

Данные хранятся, пока пользователь пользуется Сервисом. Профиль и план — до тех пор, пока пользователь не попросит их удалить (см. п. 6) либо не перестанет пользоваться Сервисом на протяжении длительного времени (в этом случае неактивные данные могут быть удалены Оператором самостоятельно).

6. Права пользователя

Пользователь вправе в любой момент запросить у Оператора:

  • какие данные о нём хранятся;
  • исправление неточных данных;
  • полное удаление данных из Сервиса.

Для этого достаточно написать Оператору по контакту, указанному в п. 1, либо через кнопку «Написать в поддержку» в разделе «Аккаунт» самого Сервиса. Запрос обрабатывается в разумный срок, не превышающий 30 дней.

7. Изменения Политики

Оператор может обновлять эту страницу — актуальная версия всегда доступна по этому же адресу. Существенные изменения (например, появление новых получателей данных) Оператор постарается заранее анонсировать в самом Сервисе.
